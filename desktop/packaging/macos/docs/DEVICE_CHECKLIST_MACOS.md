# Device checklist: macOS (MC1 and MC2 items only; the full MC7 checklist is D-v2 work)

Every item is `NEEDS-DEVICE-VALIDATION` (NDV) or `NEEDS-OWNER-VALIDATION` (NOV) until the owner pastes real output. Nothing here was run on a
Mac by the builder. Hosted-runner results are `CI (hosted VM) evidence` and never close an item of this list. Commands run in an ordinary
Terminal unless marked. Expected outputs are what a PASS looks like, not results.

Build the helper first: `swift build -c release --package-path desktop/packaging/macos/helper`.

| id | what | command | expected on a pass |
|---|---|---|---|
